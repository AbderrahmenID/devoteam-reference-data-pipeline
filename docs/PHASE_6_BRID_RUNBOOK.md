# Phase 6 BRID controlled case runbook

This additive case uses the fully synthetic BRID PDF and never overwrites the
earlier Phase 6 sample.

1. Open `11_PHASE_6_BRID_CONTROLLED_CASE.ipynb`.
2. Run all cells.
3. Confirm the final status is `TECHNICAL_PASS_READY_FOR_HUMAN_REVIEW`.
4. Open the generated `BRID_PHASE_6_REVIEW.xlsx`.
5. Review Requirements, EligibilityRules, Scoring, and Filters.
6. Use only APPROVE, REJECT, or EDIT decisions.
7. Do not run matching until all required rows are resolved.

All outputs are `SYNTHETIC_TEST_ONLY`. They are development evidence, not Devoteam pilot
acceptance or production relevance validation.
